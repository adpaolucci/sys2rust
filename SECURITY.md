# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.1.x` | :white_check_mark: |

Security of inspected system artifacts, non-injecting inspection invariants, and read-only default execution are top priorities for `sys2rust`.

If you discover a security vulnerability, parser panic, or accidental write hazard:
1. **Do not disclose it publicly** via GitHub Issues.
2. Submit a report privately via GitHub Private Vulnerability Reporting under the Security tab:
   `https://github.com/adpaolucci/sys2rust/security/advisories/new`
3. You will receive an acknowledgment within 48 hours.
4. A security patch and advisory will be coordinated and released promptly.
